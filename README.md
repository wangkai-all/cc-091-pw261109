# 数仓成本账房（虚构演示）

一个零依赖的本地看板：导入脱敏的查询访问记录（扫描量、耗时、团队归属），按团队 / 数据集 / 日期
展示资源消耗，并提供多表分摊、预算、超额原因、归属修订历史与账单预览。

所有数据、单价、预算与账单均为**虚构演示数据**，不连接任何真实计费 API，不产生实际应收。

## 运行

需要 Node.js ≥ 18（仅用内置模块，无需 `npm install`）。

```bash
npm run fixtures   # 生成确定性的虚构样例数据到 data/
npm start          # 启动本地服务，默认 http://localhost:4173
```

`PORT=4175 npm start` 可换端口。

## 测试

```bash
npm test           # 引擎/视图单元测试（32 项）
npm run smoke      # 起临时端口的接口冒烟测试（12 项）
```

## 计费与边界口径

**单表基础成本** = 扫描字节 ÷ 1 GiB × 扫描单价 + 表耗时 ÷ 1 小时 × CPU 小时单价。
查询总成本为各表基础成本之和；多表按数据集配置的规则分摊（`bytes` / `duration` / `weighted`），
权重占比用**最大余数法**落到整数分，保证各表合计严格等于查询总额。

- **重试**：同一 `logical_query_id` 只记一次账，优先记最后一次成功尝试，否则记消耗最大的尝试；
  失败/超时重复尝试的消耗单列为「未重复记账」，不进入账单。
- **取消**：取消前已经产生的计量按实际消耗照实计费（`charge_type: booked | cancelled-consumption`），
  不因状态取消而归零。
- **未知成本**：计量不完整或数据集没有配置单价时，状态为 `unknown`，金额不做估算、不摊给任何团队，
  只展示可核实的条数与扫描量；补齐数据集单价后重新导入即可重算。
- **缺归属**：单列为「未归属」，不平均分摊给其他团队，不占用团队预算。
- **跨月**：按墙钟时间（UTC）与账期的重叠时长拆分，最后一个月吸收取整余数；账单只取本期份额。
- **日期与账期**：一律按 UTC 发生时间；跨月查询按发生时间落到对应账期。

## 版本与对比

- 归属修订（`revisions`）按 `seq` 追加、按 `effective_date` 生效，账期默认使用当期最后一版；
  详情页可查看单条查询的修订历史，账单可切换到任一历史版本重述。
- 预算版本（`budgets.versions`）按 `effective_month` 生效，只影响该月及以后。
- 账单预览支持与任一较早修订对比：总额、未分配余额、预算未分配余额的「旧 → 新」，以及
  变化最大的查询（金额变化优先，纯归属迁移单列）。
- 超额原因按 `dataset_growth` → `attribution_in` → `cancelled` → `cross_month` → `budget_cut` → `other`
  的优先级占用超额额度，合计严格等于超额金额；无法解释的部分单列「其他」，不做估算。

## 导入

页面「导入脱敏记录」支持 CSV（表访问级，每行一张表）或 JSON（含 `tables` 数组的查询级记录），
上限 20,000 行。导入只写本机 `data/imported.json`，不发送到任何外部服务；SQL、用户 ID、邮箱、
手机号、IP、工号、姓名等字段在入库前剥离。可随时「恢复样例数据」删除本次导入。

## 视觉与可达性

配色取自一组已验证的分类色板（浅色/深色两套），颜色跟随团队实体而非排名；图表带图例、
表格等价视图、悬停与键盘可读的提示；堆叠段之间留 2px 表面间隙，柱宽不超过 24px。
